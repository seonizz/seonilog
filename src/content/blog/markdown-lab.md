이 글은 블로그의 글 표현을 확인하기 위한 **초안**입니다. 개발 서버에서 열어 볼 수 있으며, 공개 빌드에는 포함되지 않습니다.

## 제목과 문단

문단 사이에는 빈 줄을 하나 넣습니다. **굵게 표시할 내용**, *기울여 표시할 내용*, 문장 안의 `변수명`을 함께 사용할 수 있습니다.

### 작은 제목

본문의 큰 제목은 `##`, 그 안의 작은 제목은 `###`부터 사용합니다. 글 제목은 frontmatter의 `title`에서 표시됩니다.

> 이해한 내용을 한 문장으로 다시 설명해 보는 공간입니다.

## 목록과 링크

이번에 확인할 항목입니다.

- 코드가 읽기 쉽게 표시되는지
- 수식과 표가 작은 화면에서도 사용 가능한지
- 각주와 본문 사이를 이동할 수 있는지

순서가 있는 설명은 다음처럼 작성합니다.

1. 문제를 읽습니다.
2. 작은 예시를 만들어 봅니다.
3. 결과를 확인합니다.

[Astro Markdown 문서](https://docs.astro.build/en/guides/markdown-content/)에서 추가 문법을 확인하실 수 있습니다.

## 코드

코드 블록에는 언어 이름을 적어 주세요.

```python
def add_numbers(left, right):
    return left + right


result = add_numbers(2, 3)
print(result)  # 5
```

아래 긴 줄은 작은 화면에서 코드 영역의 가로 스크롤을 확인하기 위한 예시입니다.

```javascript
const example = { question: "무엇이 궁금했나요?", explanation: "제가 이해한 내용을 적습니다.", experiment: "작은 예시로 확인합니다.", remainingQuestion: "다음에 알아볼 질문을 남깁니다." };
console.log(example.question);
```

## 수식

문장 안에서는 $a^2 + b^2 = c^2$처럼 표시합니다.

별도 줄의 수식은 다음과 같이 작성할 수 있습니다.

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}
$$

행렬 표현도 확인해 보실 수 있습니다.

$$
A = \begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
$$

## 표

| 입력 $x$ | 규칙 $f(x) = 2x$ | 출력 |
| --- | --- | --- |
| 1 | $2 \times 1$ | 2 |
| 2 | $2 \times 2$ | 4 |
| 3 | $2 \times 3$ | 6 |

표가 넓어진 경우 표 영역을 가로로 움직여 읽을 수 있는지 확인해 주세요.

## 각주

본문의 흐름을 유지하면서 보충 설명을 붙일 수 있습니다.[^example]

두 번째 각주도 연결해 보겠습니다.[^second]

## 작성 후 확인

- 제목과 요약을 실제 글 내용에 맞게 바꿔 주세요.
- 예시를 복사했다면 설명과 출력 결과를 직접 확인해 주세요.
- 공개할 글의 `draft`만 `false`로 변경해 주세요.

[^example]: 각주에는 용어의 보충 설명이나 별도 참고 사항을 적을 수 있습니다.
[^second]: 각주에서 본문으로 돌아가는 링크도 사용할 수 있는지 확인해 주세요.
